注意：

工具處理規則說明：

  • 禁用半形字元對應（全形模式）： \ -> ＼, / -> ／, : -> ：, * -> ＊, ? -> ？, " -> ＂, < -> ＜, > -> ＞, | -> ｜。
  • 系統保留字防護： 若偵測到 CON、PRN、AUX、NUL、COM1-9、LPT1-9 等名稱，系統會自動在結尾加上底線（例如 CON_）以符合合規性。
  • 結尾去除： 自動清除名稱結尾的半形空格或點（如 test. 轉為 test）。
  • 輸出可編輯： 轉換結果可以直接在右側文字框中手動調整，複製按鈕會複製最終編輯後的內容。
  • 多行支援： 可一次輸入多行檔名，每行獨立處理。
