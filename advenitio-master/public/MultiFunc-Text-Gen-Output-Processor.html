📖 若循環 (WHILE) 語言語法手冊

若循環 (WHILE) 語言 是一個經典的演算法與理論計算機科學程式語言模型。本模擬器完全支援中文關鍵字與傳統英文關鍵字雙語混用！

語法功能 中文語法寫法 英文標準寫法
While 循環 當 (條件) 做 { ... } while (cond) do { ... } end
If 條件判斷 若 (條件) 則 { ... } 否則 { ... } if (cond) then { ... } else { ... }
變數賦值 x := 10; 或 設 x = 10; x := 10; 或 x = 10;
數值與運算 +, -, *, /, % +, -, *, /, %
邏輯比較 ==, !=, <, <=, >, >=, 與, 或 ==, !=, <, <=, >, >=, &&, ||
輸出列印 印出 x; 或 顯示 x; print x;
註解 (Comment) // 這是註解 或 # 註解 // comment

💡 除錯模式 (Debugger Mode) 使用提示：

  • 設定斷點 (Breakpoint)：點擊編輯器左側行號，會出現紅色圓點，程式自動執行至該行會暫停。
  • 單步進入 (Step Into)：每次點擊執行微小的一步（包含求值與變數賦值），並突顯目前執行的程式行。
  • 變數監視器：即時觀察變數值的改變，數值發生變化時會閃爍綠色提示。
  • 無窮循環保護：系統內建 100,000 步上限保護，防止瀏覽器當機。
